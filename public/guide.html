🐱 MEOW Agent

Quick Start Guide

👉 https://meow-agent.vercel.app

สแกนเอกสารเขียนมือ + OCR + Export เป็น Word/Excel ไว้ใจได้

🚀5 ขั้นตอนใช้งาน

1เปิด App

  • ไปที่ https://meow-agent.vercel.app
  • ใช้ได้ทั้ง PC / iPhone / Android
  • ไม่ต้อง download app ใดๆ

2ตั้ง Password (ครั้งแรก)

  • สร้าง password 4 หลักขึ้นไป
  • เก็บรหัสไว้ให้ดี (จำเป็นอย่างยิ่ง)
  • ใช้เข้าซ้ำแต่ละครั้ง
⚠️ ถ้าลืม password ต้องรีเซ็ต browser → เก็บไว้ให้ดี!

3ถ่ายรูป / เลือกรูป

  • 🎥 กด 📷 Open Camera (ถ่ายรูปสด)
  • 📁 หรือ 📁 Choose Photo (เลือกจากสต็อก)
  • ✅ ตรวจสอบรูป → กด Add Page
  • 🔁 ถ่ายหลายหน้าได้ เรื่อยๆ
💡 แสงสว่าง ชัดดี + ไม่เอียง = OCR อ่านได้ดี

4จัดเรียง + ตรวจสอบ

  • 🔄 Drag & Drop เรียงลำดับหน้า
  • 👀 Click ดูข้อความ OCR (อ่านอัตโนมัติ)
  • 🗑️ ลบหน้าที่ไม่ต้อง
  • ✅ กด ✓ Continue to Export

5Export เป็นไฟล์

  • 📄 DOCX (Microsoft Word)
    • ใช้: รายงาน, บันทึก, เอกสารธรรมชาติ
    • ✓ แก้ไขได้, เก็บรูป + ข้อความ
  • 📊 XLSX (Microsoft Excel)
    • ใช้: ข้อมูล, ตัวเลข, บันทึกย่อ
    • ✓ ตัวเลขชัดเจน, จัดระเบียบง่าย

กด Export → ไฟล์ลงมา 💾

📚Document History (ดูย้อนหลัง)

เก็บไว้กี่นาน?
✅ 7 วัน ต่อ user (อัตโนมัติลบ)

ดูยังไง?

  1. กลับไป Dashboard → 📚 Document History
  2. ต้องใส่ password เพื่อ access
  3. Export ใหม่ได้ตลอด 7 วัน
  4. Delete ด้วยตัวเองได้ถ้าต้องการ

💡Tips & Tricks

ถ่ายรูปสวยๆ

  • 📸 แสงสว่าง (ชัดดี)
  • 📏 ไม่เอียง (ตรง)
  • 📐 มองเห็นข้อความทั้งหมด
  • 🌞 หลีกเลี่ยงเงา

OCR อ่านได้ดีขึ้น

  • ✍️ หนังสือมือชัดๆ (90% แม่นยำ)
  • 🖊️ เขียนด้วยปากกา/ดินสอ
  • ⚠️ ลายมือวุ่นวายอาจอ่านผิด → แก้มือ

Export ไฟล์

  • 📄 DOCX = ร่วมไฟล์ + แก้ไขได้
  • 📊 XLSX = กรอกข้อมูล + คำนวณ
  • 💾 ไฟล์จะเก็บในโฟลเดอร์ Downloads

❓FAQ

Q: ต้อง internet ไหม?

✅ ครั้งแรกใช้ internet เพื่อเปิด app แล้ว OCR ทำงานในเบราว์เซอร์ (ไม่ upload)

Q: ข้อมูลจะไปไหน?

🔐 ทั้งหมดเก็บในเบราว์เซอร์ของคุณ ไม่ส่งให้ server ใครใช้ receive

Q: ลืม password ทำไง?

⚠️ ต้องรีเซ็ต browser storage (ค่อนข้างยุ่น) → เก็บรหัสให้ดี

Q: ใช้ได้นานไหม?

♾️ ไม่มีค่าสมัสชิก ใช้ได้นานเท่าไหร่ก็ได้ (100% free)

Q: OCR ไม่อ่านถูก?

✏️ ตรวจสอบให้ครบ → แก้ข้อความเองในไฟล์ DOCX/XLSX

🆘ติดปัญหา?

ปัญหา วิธีแก้
🎥 Camera ไม่ทำงาน อนุญาต camera ใน browser settings
📤 Export ล้มเหลว รีเฟรชหน้า → ลองใหม่
⏳ OCR ช้า รอสักครู่ (ทำงานในเบราว์เซอร์)
🔑 ลืม password ไม่มีวิธี → เก็บปลอดภัย
